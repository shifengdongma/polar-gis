三、任务 A：地图内悬停显示鼠标位置的经纬度

实现一个轻量的地图内坐标提示：
1. 鼠标进入地图可交互区域且视图分辨率达到合理门槛时，显示鼠标所指地理位置的 WGS84 经度、纬度。提示随指针移动，但不要遮住指针或拦截事件。
2. 低于门槛时隐藏地图内提示；已有底部坐标状态栏继续工作。地图外、拖动期间、触控设备没有悬停能力、地图销毁时应正确隐藏。
3. 分辨率门槛应与地图实际显示精度关联，不能简单假定 EPSG:3857 和 EPSG:3413 的相同 zoom 数字代表相同地面精度。优先用 map.getView().getResolution()、所在纬度及投影信息评估地面分辨率，必要时利用 OpenLayers 的投影点分辨率机制；设置清晰的可配置门槛，并在代码注释说明选择依据。
4. 小数位数与显示分辨率匹配；不得暗示比地图像素位置、底图数据精度更高的实际定位精度。坐标换算失败、落在投影有效范围外、得到 NaN/Infinity 时隐藏提示，不显示错误数值。
5. 跨 180° 经线时经度规范化到约定范围，避免提示跳到 181°；极区投影下也应正常工作。格式示例：“经度 123.4567° E · 纬度 74.1234° N”；负值方位的呈现保持一致。
6. 限制高频响应的 UI 开销，复用现有 pointermove 监听，使用 requestAnimationFrame 或相近机制节流；卸载时清理监听和定时任务。
7. 提示仅展示地图指针坐标，不将其写入航路 Store，也不自动创建航点。

四、任务 B：点击航线选中及地图信息浮窗

在已有 selectRouteAtPixel 流程上扩展，不再添加一个相互竞争的 Select interaction：
1. 鼠标点击可见航线时选中对应航路，保持现有高亮、面板选中和单条显隐语义；同时在点击位置附近显示信息浮窗。已隐藏航路不得被命中。点击空白区域如何关闭浮窗应与现有选中行为协调，避免意外删除或改写选中航路。
2. 浮窗至少显示：航路名、总长度（km 与海里 NM）、航点数、起点/终点坐标、按 seq 排序的航点经纬度列表。航点较多时提供可滚动区域，不让浮窗越出地图视口。
3. 点击航线的某一航段时，额外突出该段并显示该航段序号、起终航点、该段距离、截至该段终点的累计距离、该段初始真方位角。方位角必须注明“初始真方位”，不可暗示为磁方位或整段恒定航向。
4. 明确航线绘制方式与距离含义：展示的是依现有航点顺序计算的分段球面最短路径长度之和；地图上投影后的视觉线段不一定与该测地线完全重合，尤其在极区、高纬及跨日期变更线场景。不得把它称为已验证的实际可航行里程。
5. 复用现有 calculateRouteLength 或抽取共同计算逻辑，确保面板和浮窗总长度一致。距离单位换算采用 1 NM = 1852 m；考虑零长度段、重复航点、跨 180°、极区坐标和异常值。
6. 提供浮窗关闭、定位整条航路、定位所选航点等操作。定位复用现有 fitRoute 思路；不得因浮窗操作进入绘制或编辑模式。
7. 当航路名称、点位、显隐、选中状态改变，或切换投影、项目、页面时，浮窗应刷新、关闭或重新锚定，不能展示过期数据或停在错误位置。
8. 避免 hover 提示、航路浮窗、已有 Element Plus 抽屉及地图控件互相遮挡。浮窗的交互按钮可以接收点击，但其背景不能覆盖整个地图并吞掉地图指针事件。

五、任务 C：补充适合当前系统的航路显示功能

优先实现以下三项纯前端、可由现有航点可靠计算的能力：

- 起点没有入站航段，显示“—”；按 seq 顺序计算，不依赖数组偶然顺序。

C2. 航点定位

- 保持当前投影下的正确位置；跨 180° 经线时选择视觉上合理的世界副本。
- 定位不改航点数据，不触发测量或地图识别。

C3. 坐标与距离显示说明
- 在相关界面明确 WGS84、经纬度顺序、km/NM、真方位角，以及“模拟航路、仅供展示与交互验证”。
- 根据实际实现和界面空间处理：帮助提示可折叠，避免长期占据地图面积。

不要在这一阶段新增 ETA、风险分数、浅滩风险自动判断、自动避障、气象推荐航线或船舶安全航行结论。OpenCPN 等软件存在更丰富的航路属性，但本项目尚无可靠的航速、船舶参数及计算服务，不要伪造这些数据。

七、任务 E：审计并修复测距、测面积在投影切换时的行为

先分析当前实现并提交“现状—可复现问题—修复方式—验证结果”，不得未经验证就宣称原功能正确或错误。

重点检查：
1. Draw 创建的几何采用哪个 View CRS；getLength/getArea 调用时传入的 projection 是否与几何实际 CRS 一致；EPSG:3413 是否已正确注册并可被 OpenLayers 转换。
2. 在 EPSG:3857 与 EPSG:3413 中，对相同 WGS84 点组测量时，结果是否在数值容差内一致；不得用投影平面长度代替地表长度。
3. 投影切换发生在测量绘制期间时：结束旧 Draw 并清楚提示重新测量，或安全恢复绘制，但不得把旧 CRS 几何误认为新 CRS 计算。
4. 投影切换发生在测量完成后时：选择一种一致的产品行为：
   - 推荐：保留测量的 WGS84 原始点，切换后按新投影重建显示几何，结果由相同地理点重新计算；或者
   - 明确清除旧测量图形与结果，并告知用户需重新测量。
   不允许保留错误位置的旧图形，却继续显示看似有效的测量结果。
5. 测面积也执行上述投影生命周期检查；多边形闭合、跨日期变更线和极区情况要单独验证。若现有球面面积算法对跨日期变更线等复杂多边形无法保证预期，请界定支持范围并处理，不得输出明显错误结果。
6. 距离优先显示 km 和 NM（短距离可兼显 m）；面积仍用 m²/km²，不把面积换算成海里。测距结果与航路长度若采用同一组点及同一球面算法，应在舍入容差内一致。
7. 评估默认球面模型与专业航海椭球测地计算的差异；保持与现有库行为一致并在界面说明其为近似地表距离，不宣称具备航海认证精度。
