# 极地海洋环境信息平台 UI/UX 设计

## 1. 设计目标

界面应体现专业、可信、克制和高信息密度，服务于长时间桌面地图工作。Sloyka仅作为功能参考，不复制其品牌、Logo、图标、色彩或页面实现。

设计关键词：

- 海洋与极地。
- 数据可信。
- 地图优先。
- 操作可恢复。
- 状态清晰。

## 2. 视觉方向

采用“深色导航 + 浅色管理区 + 深色半透明地图面板 + 冰蓝强调色”。

管理界面采用紧凑、低装饰的专业工具风格：页面分区使用边界和克制留白建立层级，单项卡片圆角不超过8px，不把页面章节包装成浮动卡片。全局顶栏、页面标题和筛选操作区不得重复占用纵向空间；标题、说明和关键统计优先在同一行展示。地图工作台的图层行保持高密度，透明度和次级操作收纳到图层操作面板，并使用独立状态点表示等待、加载、成功和失败。

### 2.1 建议色板

| 用途 | 颜色 | 说明 |
|---|---|---|
| 深色导航 | `#0B1624` | 深海蓝黑 |
| 导航悬停 | `#13283C` | 提升层级 |
| 主色 | `#168AAD` | 海洋蓝 |
| 强调色 | `#35C3D6` | 冰川青 |
| 页面背景 | `#F3F7FA` | 冷灰白 |
| 卡片背景 | `#FFFFFF` | 主内容容器 |
| 主文本 | `#172B3A` | 深蓝灰 |
| 次文本 | `#607D8B` | 元数据 |
| 成功 | `#2F9E73` | 可用、发布成功 |
| 警告 | `#E89B27` | 演示、处理中 |
| 危险 | `#D94A4A` | 失败、删除、危险 |

最终色值应通过对比度检查，不能仅凭视觉偏好确定。

### 2.2 字体和尺寸

- 中文优先使用系统无衬线字体栈。
- 正文字号13–14px，辅助信息11–12px，管理页面标题18–22px。
- 管理区按钮和输入框高度28–32px；仅关键提交动作可使用36px高度。
- 地图工具按钮保持32–36px，并提供悬浮提示和清晰焦点状态。
- 卡片圆角不超过8px，阴影克制。
- 管理区全局顶栏建议46–52px，页面标题区建议40–48px；避免再叠加独立大尺寸面包屑栏。

## 3. 信息架构

```text
登录
├── 项目
│   ├── 项目列表
│   └── 地图工作台
└── 系统管理（仅管理员）
    ├── 用户管理
    ├── 项目管理
    ├── 数据目录
    ├── 批量导入
    ├── 导入任务
    ├── 图层与样式
    ├── 底图配置
    ├── 审计日志
    └── 系统设置
```

普通用户不显示“系统管理”入口。

## 4. 全局布局

### 4.1 管理页面

```text
┌────────────┬─────────────────────────────────────────┐
│ Logo       │ 页面标题      面包屑       用户/退出    │
│ 项目       ├─────────────────────────────────────────┤
│ 数据目录   │ 筛选、主操作                            │
│ 导入任务   │                                         │
│ 用户       │ 数据表格或编辑区域                      │
│ 审计       │                                         │
└────────────┴─────────────────────────────────────────┘
```

左侧导航固定，内容区独立滚动。导航宽度建议200–208px，菜单项使用紧凑行高。全局顶栏只保留产品标识、当前模块和系统属性提示；页面业务标题、说明和统计使用同一行的紧凑标题区。不得把退出登录绑定到整个用户区域；必须使用明确菜单项，并提供确认。

### 4.2 地图工作台

```text
┌────────────────────────────────────────────────────────┐
│ 返回/图层开关  项目名        投影切换/系统提示（浮动） │
│ 图层面板     │                          │ 查询/属性面板 │
│ 搜索         │        地图画布          │ 可展开/关闭   │
│ 分组和图层   │                          │              │
│ 图例/元数据  │                          │              │
├──────────────┴──────────────────────────┴──────────────┤
│ 坐标 | 比例尺 | 投影 | 加载状态          地图工具组    │
└────────────────────────────────────────────────────────┘
```

地图画布铺满视口，不使用满宽顶部栏。返回、图层目录开关和项目名组成连续的左侧浮动工具条，投影切换和非认证提示组成右侧控件组；图层面板标题采用单行紧凑层级，建议宽度250–270px，面板底部保留不小于16px的窗口留白。左右面板可折叠，关闭查询面板后地图自动恢复可用宽度。

## 5. 页面设计

### 5.1 登录页

- 独立品牌区与登录卡片。
- 登录页采用独立品牌区与登录卡片的专业双栏布局。左侧展示产品定位、核心能力和极地主题视觉，右侧提供清晰的登录表单与非认证航海系统提示。
- 动态场景限制设备像素比并响应系统“减少动态效果”设置；WebGL不可用时使用静态渐变背景降级。
- 显示产品名称和“非认证航海系统”简短提示。
- 用户名和密码字段有明确标签。
- 支持显示/隐藏密码。
- 登录按钮在请求期间进入加载状态，禁止重复提交。
- 错误文案不区分用户名不存在或密码错误。

### 5.2 项目列表

- 卡片显示名称、两行以内的描述摘要、图层数、更新时间和默认投影；卡片列宽限制在约 280 至 360px，使用约 76px 的视觉头部、正文和底部元信息分隔，保持紧凑而协调的横纵比例，避免做成过扁的信息条。
- 顶部提供名称搜索和新旧排序。
- 管理员可切换草稿、已发布和已归档视图。
- 普通用户只显示已发布项目。
- 项目为空、搜索无结果和加载失败使用不同空状态。

### 5.3 项目编辑

使用分区表单或步骤式编辑：

1. 基本信息。
2. 地图范围和默认投影。项目初始范围使用WGS84经纬度数组`[minLon, minLat, maxLon, maxLat]`保存；地图工作台加载和投影切换后均应定位到该范围。
3. 图层分组和配置。
4. 发布检查。

发布检查应逐项展示通过或失败原因，不使用单一“发布失败”提示。

项目的数据配置弹窗按数据集展示，一行对应一个数据集或S-57海图单元，列出数据集名称、代码、类型、当前版本和内部图层数量。管理员只配置启用、分组、默认显隐、透明度和顺序，不在此处逐项配置`SOUNDG`、`WRECKS`等内部对象层或其样式；提示文本说明保存时会自动包含当前版本内部图层并使用既有默认样式。列表使用服务端分页，跨页选择必须保持。

### 5.4 数据目录

- 表格列：名称、类型、当前版本、状态、范围、更新时间、引用项目数。
- 提供类型、状态和名称筛选。
- 详情抽屉展示原始文件、版本历史、空间元数据、图层和任务。
- 删除被项目引用的数据时显示引用项目列表。

### 5.5 上传和导入

- 上传前显示支持格式、5GB限制和压缩包要求。
- 上传过程显示文件名、大小、进度和取消操作。
- 上传完成后进入数据集信息确认，而不是自动发布。
- 导入任务展示阶段、进度、执行时间和可读错误。执行时间优先显示完成时间，处理中显示开始时间，尚未执行则显示排队时间，并以“完成 / 开始 / 排队”标记时间含义。
- S-57更新界面显示当前版次、更新号和预期下一个更新号。
- 数据目录仅承载单文件上传、数据集检索、版本管理与删除；“批量导入”作为独立管理员页面，避免将数据集目录与批次运行状态混在同一个工作区。
- 批量导入页面提供“新建批量导入”入口，并以分段控件切换“ZIP压缩包”和“本地目录”。目录选择仅支持Chrome/Edge的桌面目录能力，选择后显示识别文件数并提示被忽略的非S-57文件。批次上传显示传输进度，主表以分页方式展示总进度、已处理/总单元、成功数、失败数、状态和创建时间。
- 批次列表每3秒只刷新当前页；新增批次后回到第一页。详情抽屉按单元显示更新链、当前更新号、处理结果、状态及完整失败原因；已有数据集无新增更新时明确显示“已是最新”，长错误文本允许换行且不得撑破抽屉。
- 批次终态区分成功、部分失败和失败；部分失败不得以全局成功提示掩盖失败项。历史源文件缺失时，失败项说明需要重新提交包含对应`.000`及连续更新文件的完整目录。
- 数据目录表格上方提供紧凑工具栏：名称/代码检索、查询、重置刷新和删除选中。每行也提供“删除”操作；批量删除逐项校验引用：无引用项移入“数据清理”，仍被引用项保留并汇总展示项目清单。
- “数据清理”仅管理员可见，列出已删除数据集及其原始文件、PostGIS派生表和GeoServer资源数量，并支持多选批量永久清理。批量操作先预检全部选中项，再在确认弹窗按数据集列出完整资源清单；输入页面给出的确认文本后才执行。为避免大型 S-57 批量操作耗尽数据库 DDL 锁，已预检项按数据集逐项提交；异常时提示已完成数量并保留剩余项。确认弹窗必须明确标示不可恢复。

### 5.6 图层和样式

- 图层目录默认仅显示数据集当前有效版本的图层；历史版本图层保留用于回退和清理，但不计入默认列表总数。
- 图层详情展示数据来源、坐标系、范围、查询字段和GeoServer发布状态。
- SLD上传后先执行校验，再允许绑定。
- 图层预览与项目发布分离。
- 样式错误必须定位到具体文件和校验阶段。

### 5.7 用户管理

- 列表包含用户名、显示名称、角色、状态和最近登录时间。
- 创建和编辑使用侧边抽屉。
- 创建用户时在字段旁校验用户名格式、显示名称必填和初始密码至少 8 个字符；不满足要求时禁止提交，并显示具体原因。
- 重置密码生成一次性临时密码或由管理员输入新密码。
- 停用当前登录管理员和最后一个管理员时给出明确阻止原因。

### 5.8 列表分页

- 项目门户、用户、项目管理、数据目录、S-57导入批次、导入任务、图层目录和审计日志使用服务端分页；默认每页15条，均可切换10、15、20、50或100条。
- 分页栏显示总数、页码、前后翻页和每页条数，位于表格或卡片列表的底部；筛选条件变化和新增资源后回到第一页。
- 导入任务自动刷新仅更新当前页，不得在轮询期间改变用户所在页码。

### 5.9 审计日志

- 支持时间、用户、动作、资源类型和结果筛选。
- 默认隐藏技术细节，展开后显示请求ID和脱敏变更摘要。
- 审计记录不可编辑和删除。

## 6. 地图交互

### 6.1 图层树

- 顶部固定搜索框，支持按图层名称、代码、服务图层名和分组名称匹配；无匹配项时显示明确空状态。
- 底图选择与图层搜索组成独立的紧凑筛选组，控件之间保留明确间距；在深色地图面板中使用深色输入表面，不使用突兀的大面积纯白背景。
- 底图作为背景信息，使用低饱和、低对比度呈现，避免压过海图和环境专题图层。
- 分组支持折叠和状态统计。
- 图层目录以数据集或S-57海图单元作为可展开容器；展开后显示实际对象图层，图层行包含名称、显隐、加载状态、用户可理解的能力状态和更多操作。仅在用户显示具体图层时创建WMS地图对象；未展开数据集和默认隐藏图层不创建WMS对象。
- 更多操作包括透明度、图例、元数据和定位到图层。
- AIS 等演示或环境叠加项归入独立的”环境叠加”菜单，并显示当前启用状态。
- 临时排序只影响当前浏览会话。
- 不允许普通用户误以为临时排序已经保存。

#### S-57 图层批量加载

图层面板在搜索框与图层树之间提供紧凑的批量操作工具栏（仅当当前项目包含 S-57 数据集时显示）：

**数据集选择**：
- 每个 S-57 数据集行独立显示复选框，不展开数据集亦可勾选。
- 非 S-57 数据集不显示复选框。
- “全选当前结果”仅选中当前搜索过滤后的 S-57 数据集。
- “清空选择”清空复选框，不卸载任何已加载图层。

**批量加载下拉菜单**：
- 加载核心海图层（12 种核心对象类）
- 加载推荐海图层（核心 + 航行推荐，共 36 种）
- 加载全部可显示图层（所有有几何且可渲染的空间图层）

**批量卸载下拉菜单**：
- 卸载所选数据集图层（按数据集勾选状态）
- 卸载当前搜索结果图层（按搜索过滤结果）
- 卸载全部海图图层（仅业务海图，不影响底图/AIS/气象/测量）
- 卸载本次加载（仅最近一次批量加载创建的图层）

**进度与限制**：
- 运行时显示进度条、成功/失败/跳过数字。
- 失败详情可展开查看图层名称和具体错误。
- 取消按钮可停止尚未创建的剩余图层；已创建图层保留。
- 候选 >40 图层时弹出二次确认；>120 图层时阻止执行并提示缩小范围。
- 每批创建 5 个 WMS 图层，批间间隔 200ms。
- 单层加载失败不中断其他图层。

### 6.2 投影切换

- 提供“常规地图”和“北极投影”两种可理解名称。
- 切换前保留当前中心点，并转换到新视图可用范围。
- 不支持目标投影的图层显示禁用状态和原因。
- 跨180度经线时避免视图跳跃。

### 6.3 要素识别

- 点击地图后显示命中图层列表，不强制只返回最上层。
- 列表展示图层名和要素摘要。
- 选择要素后显示允许字段和定位操作。
- 空结果显示“当前位置没有可查询要素”。

### 6.4 属性表

- 位于右侧或底部可调整面板。
- 服务端分页，不一次性加载全部数据。
- 支持字段筛选、重置、定位和导出当前筛选结果。
- 选中行在地图高亮，地图选中要素同步表格。
- 超过导出限制时在提交前说明限制。

### 6.5 测量

- 距离和面积模式互斥。
- 显示累计距离、总面积和单位。
- 结束、撤销最后一点和清除操作明确分离。
- 切换项目或投影时清理临时测量结果并提示。

### 6.6 截图和打印

- 截图包含地图、比例尺、投影、生成时间和免责声明。
- PDF打印允许设置标题、纸张方向和是否包含图例。
- 跨域瓦片导致无法导出时给出可操作错误。

## 7. 演示数据体验

- AIS和气象入口显示“演示”徽标。
- 地图图层、弹窗、图表和导出均包含演示数据提示。
- 气象选点结果展示坐标、数据时间、单位和免责声明。
- 不显示“实时”“最新权威”等误导性词语。

## 8. 状态和反馈

### 8.1 加载

- 页面加载使用骨架屏。
- 地图图层加载使用单图层状态，不遮挡整个地图。
- 超过2秒的操作必须有进度反馈。

### 8.2 错误

- 表单错误靠近字段。
- 页面错误提供重试。
- 图层错误提供重新加载和查看详情。
- 导入错误提供阶段、摘要、请求ID或任务ID。

### 8.3 危险操作

发布、撤回、归档、停用、删除、回退和退出登录必须使用明确动作名称。删除和回退需要确认，不能只使用通用“确定”。

## 9. 可访问性与易用性

- 交互控件提供可访问名称和键盘焦点。
- 颜色不是唯一状态表达方式，同时使用图标和文字。
- 文本和关键控件满足合理对比度。
- 表格、弹窗和抽屉支持Esc关闭，但未保存表单关闭前提示。
- 图标必须配悬浮提示，禁止使用难以理解的无标签图标。

## 10. 桌面适配

- 最低宽度1366px。
- 1366px时默认只展开一个侧面板。
- 1920px时允许图层和属性面板同时展开。
- 不建设手机端断点和触摸专用交互。
